You are building the timeline layer of a knowledge graph. Extract the events from the text: things that happened, with when they happened whenever the text says so.

## What counts as an event
- Anything the text dates or places in time: a birth, a death, an appointment, a move, a release, a war, a match, a publication, an award, a merger.
- Anything that lasted over a period: an employment, a presidency, a marriage, an imprisonment, a membership, a project phase. Use time_from and time_to for these.
- Undated events only when they matter to the story (a decisive action, a turning point). Skip filler actions such as "he walked", "she said", "they waited" unless the text gives them a time.

## Requirements
- **Dated first.** Every date, year or period in the text must appear on at least one event. Do not drop a date because the sentence is mundane.
- **One event per occurrence.** "He coached A in 2001 and B in 2006" is two events.
- **Instants use one bound.** For something that happened at a moment, set only time_from. Use both bounds only for something that lasted.
- **Never invent precision.** If the text gives only a year, set year and leave month/day at their defaults and set precision to "year". "March 1996" is precision "month"; "5 March 1996" is precision "day". Do not guess a month or day.
- **Descriptions carry the facts.** Say who did what, to whom, where, and quote the relevant fragment of the text when it helps. Name the people and organizations involved in the description, using the names as the text writes them, so the event can be linked to them.
- **No duplicates.** If the same occurrence is described twice, extract it once.

## Output format
Your reply is a JSON object with an `events` list; each event has this structure:
```python
class Timestamp(BaseModel):
    year: int                      # always required
    month: int = 1                 # default when unknown
    day: int = 1                   # default when unknown
    hour: int = 0
    minute: int = 0
    second: int = 0
    precision: Optional[str] = None  # "year" | "month" | "day" | "hour" | "minute" | "second"

class Event(BaseModel):
    name: str                      # concise, specific: "Attaphol joins Buriram United as coach"
    description: Optional[str] = None
    time_from: Optional[Timestamp] = None
    time_to: Optional[Timestamp] = None
    location: Optional[str] = None
```
