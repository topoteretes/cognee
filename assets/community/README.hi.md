## Cognee कब उपयोग करें

- **Company Brain बनाएँ।** दस्तावेज़, संवाद, टिकट, कोड और एजेंट का काम साझा मेमोरी में लाएँ। टीम और एजेंट किसी निर्णय को उसकी चर्चा और इम्प्लीमेंटेशन से जोड़ सकते हैं। [Company Brain देखें](https://www.cognee.ai/company-brain)।
- **एजेंटों को रन के बीच मेमोरी दें।** प्रोजेक्ट कॉन्टेक्स्ट, पिछले निर्णय, फ़िक्स और सीखे गए नियम याद रखें। सेशन के उपयोगी सबक़ स्थायी ज्ञान में बदलें जिसे दूसरा सेशन निकाल सके। [अपना एजेंट जोड़ें](#connect-your-agent)।
- **एजेंटों को आपके डोमेन पर टिकाएँ।** मेमोरी को उन इकाइयों और संबंधों के गिर्द संगठित करें जिनकी आपके ऐप को ज़रूरत है, कस्टम डेटा मॉडल और ऑन्टोलॉजी के साथ। [ऑन्टोलॉजी देखें](https://docs.cognee.ai/guides/ontology-support)।

## क्विकस्टार्ट

**Python 3.10–3.14** चाहिए।

Cognee को **pip**, **uv** या अपने पसंदीदा Python पैकेज मैनेजर से इंस्टॉल करें।

```bash
uv pip install "cognee[gliner]"
```

### वैकल्पिक: LLM कॉन्फ़िगर करें
```python
import os

os.environ["LLM_API_KEY"] = "YOUR OPENAI_API_KEY"
```
इसके बजाय हमारे [टेम्पलेट](https://github.com/topoteretes/cognee/blob/main/.env.template) से `.env` फ़ाइल बना सकते हैं।

डिफ़ॉल्ट रूप से भाषा मॉडल और एम्बेडिंग के लिए OpenAI उपयोग होता है। प्रोसेसिंग और बने जवाब प्रोवाइडर कॉल करते हैं। दूसरे विकल्पों के लिए [इंस्टॉलेशन](https://docs.cognee.ai/getting-started/installation), [अन्य प्रदाता](https://docs.cognee.ai/setup-configuration/llm-providers) या [लोकल Ollama मॉडल](https://docs.cognee.ai/guides/local-ollama) देखें।

### बिना LLM के लोकल चलाएँ

चरण 1 में आपने "cognee[gliner]" इंस्टॉल किया।

इसे `quickstart.py` के रूप में सहेजें और `python quickstart.py` चलाएँ, या अपने LLM से यह करवाएँ:

```python
import asyncio

import cognee


async def main():
    # Extract a knowledge graph and embed the text with local models.
    await cognee.remember(
        "Marie Curie was born in Warsaw and worked at the University of Paris.",
        dataset_name="local_quickstart",
    )

    # Retrieve the matching source text; no LLM generates an answer.
    results = await cognee.recall(
        "Where was Marie Curie born?",
        datasets=["local_quickstart"],
    )
    for result in results:
        print(result)


if __name__ == "__main__":
    asyncio.run(main())
```

वही वर्कफ़्लो CLI से भी उपलब्ध है:

```bash
cognee-cli remember "Marie Curie was born in Warsaw." -d local_quickstart
cognee-cli recall "Where was Marie Curie born?" -d local_quickstart
```

टेक्स्ट इनजेशन, रिट्रीवल और सेशन स्टोरेज बिना LLM के चलते हैं। LLM पर निर्भर सुधार चरण अपने आप छोड़ दिए जाते हैं।

बने जवाब और विज़न या ट्रांसक्रिप्शन मॉडल माँगने वाली मीडिया प्रोसेसिंग को अतिरिक्त LLM कॉन्फ़िगरेशन चाहिए।

### बंडल किया गया डेमो देखें

एक्सट्रैक्शन या एम्बेडिंग मॉडल डाउनलोड किए बिना पहले से बना ग्राफ़ देखने के लिए:

```bash
cognee-cli demo
```

यह कमांड बेस `pip install cognee` पैकेज के साथ चलती है। यह बंडल किया गया सैंपल डेटा लोड करके बिना API key कीवर्ड सर्च चलाती है। अपने टेक्स्ट से ग्राफ़ बनाने के लिए ऊपर दिया लोकल क्विकस्टार्ट उपयोग करें।

## Cognee कैसे काम करता है

Cognee अलग-अलग स्रोतों से जुड़ी हुई मेमोरी बनाता है। टेक्स्ट इकाइयों, संबंधों और खोजने योग्य टुकड़ों में बदल जाता है; कोड सिंबल और निर्भरताओं के ग्राफ़ में। सेशन डिस्टिलेशन स्वीकृत सबक़ स्थायी मेमोरी में सहेजता है।

<p align="center">
  <img src="assets/remember.svg" alt="Text, code, and session guidance follow their ingestion paths into persistent Cognee memory" width="100%">
</p>

क्वेरी के समय रिट्रीवल प्रासंगिक ग्राफ़, वेक्टर या कोड कॉन्टेक्स्ट चुनता है। आपका ऐप निकाले गए सबूत देख सकता है और उसका उपयोग सवाल का जवाब देने या एजेंट का अगला काम जारी रखने के लिए कर सकता है।

<p align="center">

</p>

| ऑपरेशन | क्या करता है | और जानें |
| --- | --- | --- |
| `remember` | कंटेंट या कोड स्थायी मेमोरी में सहेजें, सेशन ID दिए जाने पर सेशन में। | [Store memory](https://docs.cognee.ai/core-concepts/main-operations/remember) |
| `recall` | ऑटोमैटिक रूटिंग या चुनी हुई सर्च रणनीति से कॉन्टेक्स्ट और जवाब निकालें। | [Query memory](https://docs.cognee.ai/core-concepts/main-operations/recall) |
| `improve` | मेमोरी समृद्ध करें, फीडबैक लागू करें और सेशन ज्ञान को ग्राफ़ से जोड़ें। | [Improve memory](https://docs.cognee.ai/core-concepts/main-operations/improve) |
| `forget` | कोई आइटम या डेटासेट हटाएँ। | [Delete memory](https://docs.cognee.ai/core-concepts/main-operations/forget) |

[आर्किटेक्चर](https://docs.cognee.ai/core-concepts/architecture) और [सेशन लाइफ़साइकल](https://docs.cognee.ai/core-concepts/sessions-and-caching) देखें।

## Cognee डिप्लॉय करें

पहले से बनी इमेज के साथ लोकल API डेमो के लिए [minimal Docker Compose गाइड](docs/minimal-docker-compose.md) देखें। इसमें परसिस्टेंट-वॉल्यूम कॉन्फ़िगरेशन और सिंगल-यूज़र डेमो सेटिंग्स की जानकारी है।

सोर्स चेकआउट से API, UI और MCP सर्वर चलाने के लिए यह रिपॉज़िटरी क्लोन करें, उसकी डायरेक्टरी में जाएँ, [`.env.template`](.env.template) को `.env` में कॉपी करके प्रोवाइडर कॉन्फ़िगर करें। फिर चलाएँ:

```bash
docker compose --profile ui --profile mcp up
```

डिफ़ॉल्ट पोर्ट API **8000**, UI **3000** और MCP **8001** हैं। लोकल डेमो से आगे डिप्लॉयमेंट के लिए [परमिशन गाइड](https://docs.cognee.ai/setup-configuration/permissions) और [डिप्लॉयमेंट टेम्पलेट](distributed/deploy/README.md) से ऑथेंटिकेशन, परसिस्टेंट स्टोरेज और संगत बैकएंड कॉन्फ़िगर करें। [Cognee Cloud](https://docs.cognee.ai/cognee-cloud/overview) मैनेज्ड विकल्प है।

डिफ़ॉल्ट Docker इमेज में GLiNER शामिल नहीं है। Docker में बिना LLM के टेक्स्ट इनजेस्ट करने के लिए अपनी इमेज में `gliner` एक्स्ट्रा जोड़ें; लोकल क्विकस्टार्ट इसे साफ़-साफ़ इंस्टॉल करता है।

## पूरी मेमोरी लेयर Postgres पर चलाएँ

ग्राफ़ मेमोरी परंपरागत रूप से एक स्टैक चलाने का मतलब है — संबंधों के लिए ग्राफ़ डेटाबेस, एम्बेडिंग के लिए वेक्टर डेटाबेस, सेशन के लिए Redis और मेटाडेटा के लिए रिलेशनल डेटाबेस — सब डिप्लॉय, सिक्योर और भुगतान किए हुए, इससे पहले कि कोई एजेंट कुछ याद करे। cognee 1.0 में आप पूरी मेमोरी लेयर एक ही Postgres इंस्टेंस पर चला सकते हैं।

> **⚠️ चेतावनी:** ग्राफ़ स्टोर के रूप में Postgres अभी डेमो फ़ीचर के रूप में रिलीज़ हुआ है। प्रोडक्शन-रेडी फ़ीचर लाइसेंस्ड प्रोडक्ट के रूप में उपलब्ध है। इसे रिलेशनल मेटाडेटा, PGVector और ग्राफ़ को साथ चलाते देखने के डेमो के लिए उपयोग करें

## बेंचमार्क और रिसर्च

[BEAM इवैल्यूएशन](cognee/eval_framework/beam/REPORT.md) सिंथेटिक लंबी-कॉन्टेक्स्ट संवादों और LLM जज के साथ संवादात्मक मेमोरी मापता है। रिपोर्ट किए गए रन Cognee के मेमोरी कंपोनेंट्स को बेंचमार्क-विशिष्ट डेटा फ़ॉर्मेटिंग, प्रॉम्प्ट और रिट्रीवल कॉन्फ़िगरेशन के साथ उपयोग करते हैं।

| BEAM कॉन्टेक्स्ट | रिपोर्टेड स्कोर (0–1) | दायरा |
| --- | --- | --- |
| 100K टोकन | **0.79** | फ़िक्स्ड हाइब्रिड रिट्रीवल; एक होल्ड-आउट संवाद के 20 सवालों पर चार इवैल्यूएशन राउंड। |
| 10M टोकन | **0.67** | एक्सप्लोरेटरी परिणाम; क्वेश्चन-टाइप रूटिंग चुनकर उसी सवाल सेट पर स्कोर किया गया, पाँच राउंड का औसत। |

दोनों सेटिंग्स अलग संवाद, इनजेशन मॉडल और रिट्रीवल-सिलेक्शन प्रक्रिया उपयोग करती हैं। इन स्कोर की दूसरे सिस्टमों से तुलना से पहले [मेथडोलॉजी, मॉडल, सीमाएँ और रिप्रोडक्शन निर्देश](cognee/eval_framework/beam/REPORT.md) पढ़ें। रिपोर्ट वितरित 10M इनजेशन के लिए बचे हुए रिप्रोडक्शन गैप को भी दर्ज करती है।

Cognee के ग्राफ़/LLM इंटरफ़ेस के पीछे की रिसर्च के लिए [Optimizing the Interface Between Knowledge Graphs and LLMs for Complex Reasoning](https://arxiv.org/abs/2505.24478) (Markovic et al., 2025) देखें।
