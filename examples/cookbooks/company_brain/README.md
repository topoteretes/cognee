# Company brain cookbooks

cognee as one shared memory for a company. Each cookbook lives in its own folder.

| Folder | What it builds |
|---|---|
| [`follow_up_agent/`](follow_up_agent/) | An agent that remembers Granola calls, Gmail and Linear, works out the next steps of your latest call (owner, team, deadline, tracked issue) and posts them to Slack. Start with its [README](follow_up_agent/README.md). |
| [`company_qa/`](company_qa/) | Your SQL database, ticket export and docs folder linked into one graph with a custom graph model, answered across, served through the API and UI, and connected to Claude Code or Codex over MCP. A sample company lets you try it first. Start with its [README](company_qa/README.md). |
| [`docs_code_conversations/`](docs_code_conversations/) | A written fact, a code repository and a rule stated in a conversation, distilled into memory and answered together from a fresh session. |
